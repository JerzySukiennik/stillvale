# Stillvale

A quiet walk through an alpine valley. Wander the meadow, listen to the birds, breathe.

**Play:** https://stillvale.gzowo.fun

- WASD to walk, Shift to run, Space to jump, mouse to look
- On phones: left thumb to walk, right thumb to look around
- Best with headphones

Built with three.js, no build step. Nature models by [Kenney](https://kenney.nl) (CC0). Ambient and effect recordings from [freesound.org](https://freesound.org) (CC0).

A Gzowo Labs game.
